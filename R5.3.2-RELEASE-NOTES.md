# R5.3.2 Resource Closure

This hotfix closes every SQLite connection created by `SqliteSharedWeightBudget`.
Python's sqlite3 connection context manager commits or rolls back transactions but
does not close the connection. On Windows this left `rate.sqlite` open and caused
R5.3 offline acceptance to fail with WinError 32 during temporary-directory cleanup.

The implementation now wraps every connection with `contextlib.closing`.
No exchange credentials are read and no exchange request is made by installation or diagnostics.
Mainnet writes remain locked.
