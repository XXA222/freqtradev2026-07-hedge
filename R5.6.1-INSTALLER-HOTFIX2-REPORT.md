# R5.6.1 Installer Hotfix 2 — Runtime Acceptance Closure

## Failures closed

The H1 package installed and ran all 17 stages, proving the packaging-only manifest fix.
Two runtime-acceptance defects remained:

1. The dynamic upstream Freqtrade schema rejected `hedge.r56` and `hedge.r561`.
2. The Windows PowerShell 5.1 AST collector used a generic `List[object]` and failed while materializing JSON with `Argument types do not match`.

The deterministic Paper scenario was also blocked because `funding_source=none` requires an ephemeral test ledger.

## Corrections

- Added strict `r56` and `r561` objects to the modular Hedge schema extension.
- Set the deterministic Paper scenario to `ephemeral=true` when Funding is disabled.
- Replaced the PowerShell generic list with a PowerShell 5.1-safe array.
- Added direct regression tests and dynamic acceptance/source-audit checks.
- Kept exchange access at NONE and mainnet writes LOCKED during installation.
