# R5.4.0 Operational Evidence and Promotion

## Summary

R5.4.0 adds the operational-evidence authority required after R5.3.2 authoritative execution.
It does not unlock mainnet writes. It provides fail-closed evidence ingestion, cumulative promotion gates,
24/72-hour observation evaluation, PostgreSQL/testnet/canary evidence schemas, backup/restore drills,
monitoring, incident drills, source/config governance, evidence bundles and continue-all diagnostics.

## Safety

- Installation and diagnostics do not read exchange credentials.
- Installation and diagnostics do not access Binance.
- Mainnet writes remain locked.
- Later stages cannot bypass missing evidence from earlier stages.
- Read-only evidence rejects any reported exchange write.
- Evidence is bound to an account, environment, payload hash and optional expiry.
