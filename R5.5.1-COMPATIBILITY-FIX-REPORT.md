# R5.5.1 Compatibility Closure Report

R5.5.1 closes the three compatibility regressions found by the Windows Continue-All run on 2026-08-05.

## Fixed regressions

1. `ReplayCheckpoint` exposes backward-compatible `signal_target_net_quantity` and `signal_target_net_ratio` properties while preserving the R5.5 canonical fields.
2. `ReadonlyPlanningContextBuilder` accepts both R5.5 rich strategy signals and legacy R3.x signal objects. Missing optional fields receive conservative defaults and cannot increase static risk limits.
3. `hedge.dashboard` is accepted by the central Hedge configuration validator and its nested keys are fail-closed against an explicit allowlist.

## Diagnostic policy

The installer attempts every available diagnostic stage, records every result, and rolls back only R5.5.1/R5.5 changes when any stage fails. Mainnet writes remain locked and the installer performs no exchange requests.
